# AutoText

Fabric mod for Minecraft 1.21.11.

Requires JDK 21.

## Build

macOS / Linux:

```sh
./gradlew build
```

Windows:

```bat
gradlew.bat build
```

Output: `build/libs/autotext-0.1.0+1.21.11.jar`.

Runtime dependencies: Fabric Loader, Fabric Language Kotlin and OneConfig v1, as listed in `fabric.mod.json`.
